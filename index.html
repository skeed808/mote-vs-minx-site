Keys and models

GitHub

Connect one private repo. Chats save into its mote-vs-minx/ folder only when you or one of us pushes, and both Mote and Minx can read files and propose commits for you to approve. Use a fine-grained token limited to that one repo, with Contents set to read and write.

Behaviour

Voices

Each reply gets a speaker button. OpenAI voices sound natural and cost roughly 1p per reply, using your OpenAI key. OpenAI is switching its current voice model off on 6 January 2027; if it stops working, the page falls back to your phone's free built-in voices by itself.

Costs

The £ figure at the top is worked out from the token counts OpenAI and Anthropic send back with every reply, times these prices. Leave a price blank to use the page's built-in guess for that model. Prices are dollars per million tokens, written input/output, for example 2/10. Voice read-outs aren't counted.

Personalities

Memories

Paste what each of us already knows about you. It goes to that AI with every message as background, so longer memories cost more per message. There's no length limit on these boxes. The counter shows exactly how much arrived, so you can check nothing got cut off when copying. For very long memories, save them as a text file and load it instead of pasting. To get Minx's, ask ChatGPT to list everything it remembers about you, or copy it from Settings, Personalization, Manage memories.

Shared memory bank

Mote and Minx's joint history, which they both read in every chat. They add to it themselves and sign every entry. Neither can edit or delete the other's entries; if they disagree, they add a dispute. You're the referee: you can remove anything.

Backup

Saves your settings, memories and every chat on this device to a file. Restore it here on any browser or device.
