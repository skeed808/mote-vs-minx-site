Memories

Paste what each of us already knows about you. It goes to that AI with every message as background, so longer memories cost more per message. There's no length limit on these boxes. The counter shows exactly how much arrived, so you can check nothing got cut off when copying. For very long memories, save them as a text file and load it instead of pasting. To get Minx's, ask ChatGPT to list everything it remembers about you, or copy it from Settings, Personalization, Manage memories.
